# Java Collections & Advanced Topics

## Collections Framework
- **List**: Ordered collection permitting duplicates (`ArrayList`, `LinkedList`, `Vector`).
- **Set**: Unordered collection prohibiting duplicate elements (`HashSet`, `TreeSet`, `LinkedHashSet`).
- **Map**: Key-Value pair mapping (`HashMap`, `TreeMap`, `ConcurrentHashMap`).

## Memory & Execution
- **Heap Memory**: Stores objects and JRE classes created at runtime.
- **Stack Memory**: Stores primitive local variables and method call frames.
